## 1. Введение

**Marketplace** — пет-проект веб-приложения маркетплейса на Spring Boot. Реализует базовые сценарии электронной коммерции: регистрацию с ролями, витрину товаров, корзину и оформление заказов.

**Стек:** Java 17, Spring Boot, Spring Security, PostgreSQL, Thymeleaf, Bootstrap 5.

Ниже — пошаговая демонстрация всех функций с скриншотами.

## 2. Главная страница

Главная страница — точка входа для покупателя. Здесь отображаются **последние добавленные товары**, чтобы сразу было видно, что на площадке есть жизнь.

В шапке — навигация: каталог, корзина и кнопка входа/регистрации (или профиль, если пользователь авторизован).

Каждый товар представлен карточкой с изображением, названием и ценой. Клик по карточке ведёт на детальную страницу товара.
